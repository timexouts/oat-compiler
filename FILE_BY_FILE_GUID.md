
# Original Submission Files

This repository preserves the original source code
submitted during the ETH Zürich Compiler Design course.

The project was developed jointly by two students.

## Assignment Overview

| Assignment | Submitted Files | Purpose |
|---|---|---|
| HW01 | hellocaml.ml, providedtests.ml | OCaml introduction |
| HW02 | simulator.ml | x86 simulator |
| HW03 | backend.ml | LLVMlite backend |
| HW04 | lexer.mll, parser.mly, frontend.ml | Lexer, parser, frontend |
| HW05 | frontend.ml, typechecker.ml | Extended frontend, type checking |
| HW06 | solver.ml, alias.ml, backend.ml, dce.ml, constprop.ml | Analyses, register allocation, optimizations |

## Source Code Attribution

Files in `original-submissions/` correspond to the
original team submissions.

The `compiler/` directory contains the complete final
HW6 project, including course-provided infrastructure
and potentially reference implementations.

The code in `compiler/` should not be interpreted as
entirely student-authored.

Earlier submission files should not be copied into
the final compiler without checking compatibility.
